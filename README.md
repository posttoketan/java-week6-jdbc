# Week 6 - Java JDBC and CRUD Operations

## Internship Project

This repository contains practical Java programs developed during Week 6 of the Java Development Internship at YuvaIntern. The main objective is to understand JDBC connectivity and perform database operations using Java and SQLite.

## Technologies Used
- Java
- JDBC (Java Database Connectivity)
- SQLite Database
- SQL

## Topics Covered

1. Database Connection
2. Creating Database Tables
3. Inserting Records
4. Retrieving Records
5. Updating Records
6. Deleting Records
7. Transaction Management
8. Complete CRUD Application

## Project Structure

- `01-DatabaseConnection/` - Establishing database connection
- `02-CreateTable/` - Creating employee table
- `03-InsertRecord/` - Inserting employee records
- `04-RetrieveRecord/` - Retrieving employee details
- `05-UpdateRecord/` - Updating employee information
- `06-DeleteRecord/` - Deleting employee records
- `07-TransactionManagement/` - Managing database transactions
- `08-CRUDApplication/` - Complete CRUD application

## CRUD Operations

CRUD stands for Create, Read, Update and Delete. These operations are used to manage employee records in the database.

## Key Learning Outcomes

- Understanding JDBC architecture and database connectivity.
- Using Connection, Statement, PreparedStatement and ResultSet.
- Executing SQL queries through Java.
- Performing CRUD operations on employee records.
- Managing transactions using commit and rollback.
- Handling SQL exceptions and database resources.

## Database

The project uses SQLite with the database file `enterprise_erp.db`. The SQLite JDBC driver is required to execute the programs.

## Conclusion
This project provides practical experience in connecting Java applications with databases and managing records using JDBC. It strengthens the understanding of database programming and prepares for developing real-world Java applications.
